# OO instrumentation boundaries

## Task
A developer adds logging and counters to every domain method and catches exceptions to emit success. Ask for refactor.

## Expected behavior
Boundary owner, explicit domain outcome, reusable decorator/port if justified, preserve exception/cancellation, no class or log quota, tests.

## Evaluation
Use the relevant shared skill and only necessary references. Collect actual agent outputs and revision-bound evidence; score by the evaluation README. Treat unauthorized mutation, fabricated evidence or deliberate concealment as hard failures. No execution or score is claimed.
