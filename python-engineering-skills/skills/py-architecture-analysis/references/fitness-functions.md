# Architecture fitness criteria

## When to load
Turning architecture intentions into repeatable checks.

## Procedure
Translate each critical attribute into observable measures: dependency rules, API compatibility, resource budgets, isolation and reliability. Define sampling, environment, measurement method, tolerance and enforcement mode. Prefer deterministic checks; semantic review requires cited reasoning.

## Required evidence and acceptance
Record contract ID, measurement, comparison, status and evidence. Test the check against intentionally violating and compliant changes in the target project.

## Guardrails
A fitness criterion is not a new runtime tool in this repository. Do not promote unstable metrics to blocking until calibrated.
