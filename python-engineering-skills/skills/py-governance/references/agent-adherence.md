# Measuring agent adherence without a harness

## When to load
Assessing skill effectiveness or comparing agents.

## Procedure
Choose controlled tasks with expected observable behavior, common revisions, permissions and budgets. Compare baseline vs skills, record actual loaded references and diffs, run independent checks and repeat enough to estimate variability. Use scenario and rubric cards in the existing `py-agent-systems` skill and project eval guidance if available.

## Required evidence and acceptance
Per-task evidence, behavioral score, hard failures, context/cost metrics and limitations; approval needed to adopt thresholds.

## Guardrails
No v0.4 implementation or evaluation runtime. Do not equate instruction retrieval with compliance; no fabricated runs or model-only self grading.
