# Context-efficient role routing and compaction

## When to load
Skills are used by agents with limited context.

## Procedure
Load mandatory policy, router and relevant skill only; start with one or two cards per concrete question. Reviewers load decision protocol and relevant gate cards, not implementation catalog. Record loaded paths, policy, decisions and evidence in a compact handoff; re-read critical contract after compaction.

## Required evidence and acceptance
Traceable loaded-card list and rationale; necessary security and verification criteria retained.

## Guardrails
Do not recursively load the whole repository. Context budget is soft when correctness/security requires more; never drop a mandatory requirement to save tokens.
