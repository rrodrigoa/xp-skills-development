# Naming conventions

## Use when
Creating or reviewing identifiers.

## Avoid when
Abbreviations only familiar to their author.

## Implementation
Use snake_case for functions and variables, PascalCase for classes, UPPER_CASE constants. Use domain nouns for types and verbs for operations; predicates is_/has_/can_; name units in ambiguous quantities. Avoid Manager, Helper, data and process unless domain-specific.

## Verification and review
Names reveal intent without comments; preserve public names or deprecate deliberately.
