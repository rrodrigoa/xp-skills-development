# Naming conventions

## Use when
Creating or reviewing identifiers.

## Avoid when
Abbreviations only familiar to their author.

## Implementation
Follow language-specific casing conventions consistently. Use domain nouns for types and verbs for operations; predicate names that clearly express a boolean condition; name units in ambiguous quantities. Avoid Manager, Helper, data and process unless domain-specific.

## Verification and review
Names reveal intent without comments; preserve public names or deprecate deliberately.
