# Formal evidence review and regression

## When to load
Formal result participates in release approval.

## Implementation in the target project
Freeze spec/model/proof and implementation revisions; inspect changed theorem statements, assumptions, config bounds, axiom policy and tool status. Run negative controls and verify discovery of all required properties. Require independent review of weakened claims, increased exclusions and skipped checks. Record timeout or state-space limit as unknown where required.

## Required evidence and acceptance
Evidence includes exact properties and scope, results, correspondence and unresolved limitations. Reviewer can reproduce or authenticate checks.

## Guardrails
Proof checker success does not validate changed requirement; never treat timeout or admitted proof as success.
