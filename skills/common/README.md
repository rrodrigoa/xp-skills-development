# Common skills

Canonical language-independent engineering guidance.
- [dev-agent-factory](dev-agent-factory/SKILL.md) — Scale verified inner loops through explicit graphs, independent evaluators, bounded repair, release fuzzing, safe self-improvement and controlled automation. (10 cards)
- [dev-agent-systems](dev-agent-systems/SKILL.md) — Design production AI agents, MCP tools, LLM adapters, structured outputs, workflow state, safety and evaluation. (9 cards)
- [dev-alerting](dev-alerting/SKILL.md) — Design actionable SLO and threshold alerts, evaluate rules, route notifications, test delivery, reduce fatigue and guide safe response. (18 cards)
- [dev-architecture-analysis](dev-architecture-analysis/SKILL.md) — Audit software architecture, dependency graphs, coupling, cohesion, complexity, contracts, and architectural regressions. (17 cards)
- [dev-delivery](dev-delivery/SKILL.md) — Create project scaffolds, packaging, dependency management, CI, releases, versioning and reproducible development workflows. (8 cards)
- [dev-deterministic](dev-deterministic/SKILL.md) — Bootstrap enforceable engineering environments; convert recurring agent mistakes into code constraints, verified checks and reproducible development workflows. (11 cards)
- [dev-enforcement](dev-enforcement/SKILL.md) — Design and validate machine-enforced architecture rules, custom lint, type constraints, test oracles, CI checks and anti-bypass policies in target projects. (11 cards)
- [dev-engineering](dev-engineering/SKILL.md) — Route software engineering tasks; apply mandatory quality rules, select minimal references, plan changes and verify results. (1 cards)
- [dev-formal-verification](dev-formal-verification/SKILL.md) — Specify invariants, model check distributed and concurrent behavior, prove algorithms and connect formal evidence to real implementation. (9 cards)
- [dev-governance](dev-governance/SKILL.md) — Establish versioned project standards, role boundaries, exceptions, quality baselines, continuous improvement and accountable agent workflows. (16 cards)
- [dev-grafana](dev-grafana/SKILL.md) — Design READS dashboards, query metrics/logs/traces, correlate evidence, validate and govern Grafana assets and monitoring investigations. (15 cards)
- [dev-implementation](dev-implementation/SKILL.md) — Implement professional libraries, APIs, CLI tools, naming, type contracts, errors, documentation and reusable components. (16 cards)
- [dev-migration](dev-migration/SKILL.md) — Plan pattern-driven refactoring, reusable design blueprints, code generation specifications and safe automated migrations. (15 cards)
- [dev-observability](dev-observability/SKILL.md) — Design, implement, test and diagnose metrics, logs, traces, context, OpenTelemetry pipelines, agent telemetry and safe instrumentation. (20 cards)
- [dev-quality-gates](dev-quality-gates/SKILL.md) — Evaluate PRs, architecture regressions, test quality, security and delivery evidence; issue reproducible merge recommendations. (31 cards)
- [dev-reads](dev-reads/SKILL.md) — Define and reason about Request rate, Errors, Availability, Duration and Saturation; health contracts, SLIs, SLOs and diagnosis. (17 cards)
- [dev-refactoring](dev-refactoring/SKILL.md) — Refactor procedural or anemic code, large modules, god objects, duplicated code, coupling and legacy APIs without behavior regressions. (12 cards)
- [dev-reliability](dev-reliability/SKILL.md) — Engineer software reliability, security, observability, concurrency, performance, data integrity and resilient I/O. (12 cards)
- [dev-runtime-verification](dev-runtime-verification/SKILL.md) — Give agents controlled application execution, feature maps, reusable drivers, statecharts, reproducible tests and inspectable proof artifacts. (11 cards)
- [dev-testing](dev-testing/SKILL.md) — Design unit, integration, contract, end-to-end, property, negative, penetration and regression tests; coverage and test doubles. (13 cards)
- [oo-design](oo-design/SKILL.md) — Design object models, boundaries, SOLID, dependency injection, modular packages, domain and service layers. (25 cards)
- [oo-patterns](oo-patterns/SKILL.md) — Select and implement classic OO and enterprise patterns across languages; compare alternatives and avoid unnecessary abstractions. (35 cards)
