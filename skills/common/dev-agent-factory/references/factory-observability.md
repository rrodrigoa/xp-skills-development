# Observe development factory effectiveness

## When to load
Operating agent workflows at scale.

## Implementation in the target project
Instrument run rate, terminal failures, correct completion, duration and saturation; distinguish runs, attempts and PRs. Track check failure categories, flaky retries, evidence gaps, review burden, reverts, fix-forward defects, cycle time, cost per accepted change and user impact. Use READS and telemetry contracts; build cohort comparisons by policy/model/tool versions.

## Required evidence and acceptance
Dashboards and alerts reflect validated definitions, baselines and data freshness; no unbounded identifiers in metrics; improvements demonstrated with actual outcome evidence.

## Guardrails
Revert rate is incomplete; do not optimize PR count or automated merge percentage at the expense of quality.
