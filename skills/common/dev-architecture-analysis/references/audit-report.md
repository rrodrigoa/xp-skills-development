# Architecture audit report and prioritization

## When to load
Delivering a review to an implementation agent or owner.

## Procedure
Classify findings as confirmed contract violations, demonstrated design problems, heuristic signals or unknown. For confirmed items state impact, path, evidence, baseline delta and remediation options. Prioritize correctness, security and business risk before aesthetics. Group work into independently testable slices.

## Required evidence and acceptance
Deliver an inventory, graph limitations, prioritized findings and acceptance criteria for each slice; link policy IDs where applicable.

## Guardrails
Do not claim all findings are proven or all debt must be fixed in the current PR. No unauthorized implementation during review.
