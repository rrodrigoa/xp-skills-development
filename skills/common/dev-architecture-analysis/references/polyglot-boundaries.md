# Polyglot architecture inventory

## Procedure
Map language and build roots, deployable units, libraries, schemas and external dependencies. Distinguish logical ownership from physical processes and repositories. For every cross-language edge record protocol, direction, identity, version negotiation, data ownership and failure handling. Inspect deployment metadata, generated sources and actual clients; don't infer a runtime edge merely from a shared schema. Explicitly identify native bindings, reflection and dynamic dispatch blind spots.

## Evidence
Produce a component table and typed dependency edges, revision and coverage exclusions. Verify each critical edge against source or runtime evidence. Identify shared policy duplicated across languages and choose an authoritative owner or contract test. Do not count class or method metrics across languages as if they were directly comparable.
