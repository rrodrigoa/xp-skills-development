# Governance policy review and release

## When to load
Publishing a new skill or standards version.

## Procedure
Check source provenance, conflicts, stable rule IDs, scope, discoverability, cross-references, prose-only requirement and scenario coverage. Compare old/new semantics and update profiles only after approval. Validate sample decisions and exception cases on paper before rollout.

## Required evidence and acceptance
Review checklist, approved change summary, version identity, migration notes, known limitations and adoption guidance.

## Guardrails
Do not claim host enforcement, live evaluations or runtime validation without evidence. No executable artifacts or bundled automation in this repository.
