# End-to-end agent engineering workflow

## When to load
Orchestrating a feature, fix or refactor through several agents.

## Procedure
Intake scope and revision; classify risk; choose skills; produce design and acceptance contracts; implement a vertical slice; verify behavior; conduct independent review; resolve findings; rerun affected checks; return recommendation for authorized merge. On revision change invalidate affected evidence and re-review.

## Required evidence and acceptance
Handoff records at each stage; all final evidence bound to same candidate and policy; unfinished work explicitly tracked.

## Guardrails
Avoid infinite loops and parallel edits to same files; set iteration/time budgets, stop on blockers and escalate.
