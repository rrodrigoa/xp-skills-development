# Governance

This skill is for maintainers, orchestration agents, independent evaluators and policy owners. It defines a governance process, not a runtime. Begin with the project profile and authority model. Never allow a coding or reviewing agent to silently amend the policy it is being evaluated against. Use `dev-quality-gates` for a specific merge decision; use this skill for policy lifecycle, adoption and governance of multiple agents.
